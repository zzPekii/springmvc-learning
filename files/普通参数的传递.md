# 普通参数的传递

# 1. Get 方法接受参数

```java
  @RequestMapping("/commParam")
  @ResponseBody
  public String commParam(String name, int age) {
      System.out.println("name == " + name + " age == " + age);
      return "{'module': 'commParam'}";
  }
```

# 2. Post 方法

在PostMan里面发Post请求需要用 `x-www-form-urlencoded` 的形式去发请求

`form-data` 不仅能发表单还能发文件

但是不能处理中文，我们需要回到原来的servletconfig类中进行添加过滤器

```java
// solve chinese character
// create filter then put into container
@Override
protected Filter[] getServletFilters() {
    CharacterEncodingFilter filter = new CharacterEncodingFilter();
    filter.setEncoding("UTF-8");
    // f1, f2, f3, 我们可以插入很多个filter在这里
    return new Filter[]{filter, f2, f3 ...};
}
```
