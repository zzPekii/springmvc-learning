# 请求映射路径

# 1. 请求路径前缀

看看下面这个案例

```java
    @RequestMapping("/user/save")
    @ResponseBody
    public String save() {
        System.out.println("save!");
        return "User is saving";
    }

    @RequestMapping("/user/commParam")
    @ResponseBody
    public String commParam(String name, int age) {
        System.out.println("name == " + name + " age == " + age);
        return "{'module': 'commParam'}";
    }

    @RequestMapping("/user/delete")
    @ResponseBody
    public String delete() {
        System.out.println("user delete");
        return "{'module' : 'user delete'}";
    }
```

当我们在开发的时候，有很多个router都需要挂user，会很容易搞错

我们可以在最前面标注出来，也就是标注**请求路径的前缀**

```java
@Controller
@RequestMapping("/user") // 这里标注
public class UserController {
    public UserController() {
        System.out.println("Controller is loaded");
    }

    @RequestMapping("/save")
    @ResponseBody
    public String save() {
        System.out.println("save!");
        return "User is saving";
    }

    @RequestMapping("/commParam")
    @ResponseBody
    public String commParam(String name, int age) {
        System.out.println("name == " + name + " age == " + age);
        return "{'module': 'commParam'}";
    }

    @RequestMapping("/delete")
    @ResponseBody
    public String delete() {
        System.out.println("user delete");
        return "{'module' : 'user delete'}";
    }
}
```
