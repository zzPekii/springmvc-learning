# Spring MVC 入门体验

# 体验流程

1. 创建web工程（Maven结构）
2. 设置tomcat服务器，加载web工程（tomcat插件）
3. 导入坐标（SpringMVC+Servlet）
4. 定义处理请求的功能类（UserController）
5. 设置请求映射（配置映射关系）
6. 讲SpringMVC设定加载到Tomcat容器中

## 1. 导入SpringMVC坐标与Servlet坐标

```xml
  <dependency>
    <groupId>javax.servlet</groupId>
    <artifactId>javax.servlet-api</artifactId>
    <version>3.1.0</version>
  </dependency>
  <dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-webmvc</artifactId>
    <version>5.2.10.RELEASE</version>
  </dependency>
```

## 2. 初始化Spring MVC环境

```java
@Configuration

public class SpringMvcConfig {

}
```

## 3. 创建Spring MVC控制器类

```java
@Controller
public class UserController {

    // 映射 否则无法访问
    @RequestMapping("/save")
    @ResponseBody
    public void save(){
        System.out.println("User save ...");
        // Responsebody 告诉 print mvc 下面的就是响应体
    }
}
```

## 4. 设定Spring MVC加载对应的bean

其实也就是加上扫描

```java
@Configuration
@ComponentScan("com.harris.controller")
public class SpringMvcConfig {

}
```

这样springmvc就可以加载到我们的控制器类

## 5. 初始化servlet的容器

```java

public class ServletContrainersInitConfig extends AbstractDispatcherServletInitializer {

    @Override
    protected WebApplicationContext createServletApplicationContext() {
        // 要求你在这里加载mvc的容器对象
        AnnotationConfigWebApplicationContext ctx = new AnnotationConfigWebApplicationContext();
        ctx.register(SpringMvcConfig.class);
        return ctx;
    }

    @Override
    protected String[] getServletMappings() {
        // 哪些请求归springMvc处理
        // 这里表示所有的请求归spring管
        return new String[]{"/"};
    }

    @Nullable
    @Override
    protected WebApplicationContext createRootApplicationContext() {
        // 加载Spring对应的容器配置，这里return null就行了
        return null;
    }
}

```

## 6. 设置请求方法返回值为字符串，并返回自定义的json数据

```java
@Controller
public class UserController {

    // 映射
    @RequestMapping("/save")
    @ResponseBody
    public String save(){
        System.out.println("User save ...");
        // Responsebody 告诉 print mvc 下面的就是响应体
        return "{'info' : springmvc'}";
    }
}

```

# Servlet 容器初始化类

AbstractDispatcherServletInitializer 类是Spring MVC提供的初始化Web3.0容器的抽象类，它提供了3个方法，需要实现

## 1. createServletApplicationContext()

是用来加载容器的，通过上下文初始化容器对象，通过register得方法，将配置注册到容器中，返回回去

一旦tomcat启动，就会把这个容器加载到tomcat的容器中。这样我们可以在tomcat中访问到sprintmvc的容器，后面的bin也就能正常访问

```java
    @Override
    protected WebApplicationContext createServletApplicationContext() {
        // 要求你在这里加载mvc的容器对象
        AnnotationConfigWebApplicationContext ctx = new AnnotationConfigWebApplicationContext();
        ctx.register(SpringMvcConfig.class);
        return ctx;
    }
```

## 2. getServletMappings()

设定哪些请求归springmvc处理

```java
    @Override
    protected String[] getServletMappings() {
        // 哪些请求归springMvc处理
        // 这里表示所有的请求归spring管
        return new String[]{"/"};
    }
```

## 3. createRootApplicationContext()

加载除了springmvc之外的容器的内容，没有就`return null`

```java
    @Nullable
    @Override
    protected WebApplicationContext createRootApplicationContext() {
        // 加载Spring对应的容器配置，这里return null就行了
        return null;
    }
```
